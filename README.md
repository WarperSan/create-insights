# Create: Insights

[![CurseForge](https://img.shields.io/curseforge/dt/1737107?logo=curseforge&label=&suffix=%20&style=flat&color=242629&labelColor=e04e14&logoColor=1c1c1c)](https://www.curseforge.com/minecraft/mc-mods/create-insights)
[![Modrinth](https://img.shields.io/modrinth/dt/create-insights?logo=modrinth&label=&suffix=%20&style=flat&color=242629&labelColor=5ca424&logoColor=1c1c1c)](https://modrinth.com/mod/create-insights)

A [Create](https://github.com/Creators-of-Create/Create) mod add-on adding more information to the Goggles's overlay.

![Demonstration of Blaze Burner Heating](https://raw.githubusercontent.com/WarperSan/create-insights/refs/heads/main/assets/blaze-burner-heating.png)

## Features

This mod adds a bunch of tooltips to help players understand their machines better:
- Progress bar for **Millstone** and **Crushing Wheel**
- Remaining Heat Time for **Blaze Burner**
- Push Distance for **Encased Fan**
- Time until Next Pulse for **Pulse Repeater** and **Pulse Timer**
- Time until Depleted for **Pulse Extender**
- Content of **Depot**
- Durability of the equipped tool of **Deployer**
- Fluid Transfer Rate for **Mechanical Pump**
- Distribution Mode for **Brass Tunnel** and **Mechanical Arm**

![Demonstration of Millstone Progress](https://raw.githubusercontent.com/WarperSan/create-insights/refs/heads/main/assets/millstone-progress.png)

## Compatibility

This mod overrides Create's default tooltip rendering. Other mods that add tooltips directly using the original rendering **will not work**.

However, if your mod uses `IHaveGoggleInformation`, the tooltip will also work here.
